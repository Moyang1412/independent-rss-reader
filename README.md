# 本地 RSS 阅读器

一个独立的 Obsidian 插件，用于在库内阅读个人 RSS 和 Atom 订阅。

采用 MIT 许可证，不连接乔木服务，也不包含播客、实验室、Agent 或乔木品牌功能。语音识别通过可选的 DeepSeek 适配器提供。

## 功能

- 支持 RSS 2.x、RSS 1.0/RDF 和 Atom 1.0；
- 添加个人订阅，并可编辑地址、名称和分组；
- OPML 粘贴或文件导入和库内导出；
- 文章搜索、未读、收藏和稍后读；
- 当前订阅全部标记为已读；
- 上一篇/下一篇导航和 `j`/`k`、方向键、`r` 阅读快捷键；
- 文章列表和正文中的文章来源显示；
- 最近 7 天文章筛选；
- 安全清理文章 HTML 和链接；
- 本地保存订阅、文章状态和阅读数据；
- 使用 Obsidian 核心 Daily Notes 设置写入今日日记。
- 可选配置 DeepSeek API，为当前文章生成摘要；不配置 API 时本地阅读仍可独立使用。
- 可选使用 DeepSeek 语音搜索；支持 16-bit PCM WAV 和 Ogg Opus。

## 安装

从 [GitHub Releases](../../releases) 下载最新 zip，解压到你的 Obsidian 库：

```text
<你的库>/.obsidian/plugins/independent-rss-reader/
├── main.js
├── manifest.json
├── styles.css
└── LICENSE
```

然后在 Obsidian 中打开“设置 → 第三方插件”：

1. 如果启用了安全模式，先关闭安全模式；
2. 在已安装插件中找到“本地 RSS 阅读器”；
3. 打开插件开关。

插件 ID 是 `independent-rss-reader`。

## 使用

### 打开阅读器

启用插件后，点击左侧 RSS 图标，或在命令面板中运行“打开本地 RSS”。

### 添加 RSS 或 Atom

1. 点击阅读器顶部的“+”；
2. 输入 RSS 或 Atom 地址，例如：

   ```text
   https://www.ruanyifeng.com/blog/atom.xml
   ```

3. 填写可选的名称和分组；
4. 点击“添加”。

插件会从该地址读取并解析订阅内容。订阅地址必须是 HTTP(S) 地址，不能包含用户名或密码。

在左侧订阅上点击右键，可以编辑地址、名称和分组，也可以暂停、恢复或单独刷新该订阅。

拖动左侧订阅可以调整顺序。删除订阅时，可以选择保留文章；保留的文章会出现在“已保存文章”中。

### 导入和导出 OPML

- 在命令面板运行“导入 OPML”，粘贴 OPML 内容或点击“选择文件”导入 `.opml/.xml` 文件；
- 在命令面板运行“导出 OPML”，文件会保存到库内的 `RSS Exports/subscriptions.opml`。

导入会自动跳过重复地址和无效地址。

### 刷新订阅

点击阅读器顶部的刷新按钮，或运行“刷新 RSS 订阅”命令。刷新完成后会显示成功更新的订阅数量。暂停的订阅会被跳过；网络失败时，已有本地文章仍会保留。左侧订阅列表会显示未读数量、最近更新时间和失败状态。

### 阅读文章

在左侧选择订阅，在文章列表中选择文章。你可以：

- 使用搜索框搜索标题和摘要；
- 按全部、未读、收藏、稍后读或最近 7 天筛选；
- 点击“全部已读”将当前订阅中的文章全部标记为已读；
- 点击“上一篇”或“下一篇”在当前筛选结果中移动；
- 使用 `j`/`k` 或方向键切换文章，使用 `r` 刷新当前订阅；
- 在文章列表和正文中查看文章来源；
- 打开原文链接；
- 收藏文章或加入稍后读。

快捷键只在阅读器内容区域生效。搜索框、输入框和可编辑区域获得焦点时，插件不会拦截键盘输入。

文章正文会在显示前清理脚本、危险链接、嵌入页面和表单内容。

### 记到今日日记

“记到今日日记”会读取 Obsidian 核心 Daily Notes 插件的设置，不使用本插件单独的目录配置。

请先在 Obsidian 核心插件中配置：

- 日记目录；
- 日期格式；
- 模板文件。

打开文章后点击“记到今日日记”，插件会按照这些设置定位当天的 Markdown 文件，并追加文章标题和原文链接。重复点击同一篇文章不会重复追加。

### 配置 DeepSeek 摘要

在插件设置中启用 DeepSeek，填写 API Key，并按需修改接口地址和模型。默认接口地址是 `https://api.deepseek.com`，默认模型是 `deepseek-flash`。启用后，打开文章即可请求摘要；摘要请求只发送当前文章的标题、摘要和正文，不会上传整个库、订阅列表或阅读状态。

DeepSeek 配置是可选适配器。没有 API Key、关闭适配器或请求失败时，RSS 添加、刷新、搜索、阅读、收藏和今日日记功能仍然可以正常使用。API Key 只保存在本地插件数据中，不写入日志或文章内容。

### DeepSeek 语音搜索

在插件设置中启用 DeepSeek 并填写 API Key。阅读器搜索框旁提供“开始录音”和“选择音频”两个入口。点击“开始录音”后直接说话，再点击“停止录音”；插件会在本地把录音编码为 16-bit PCM WAV，然后发送识别。你也可以选择已有的 WAV 或 Ogg Opus 文件。单个音频最多 8 MiB、120 秒；DeepSeek 自动检测语言，不需要填写语言参数。录音需要 Obsidian 的麦克风权限。音频只在你主动开始录音或选择文件后上传，识别结果不会自动写入笔记。

## 数据和隐私

- RSS 内容直接从你添加的订阅地址读取；
- 不连接乔木后端；
- DeepSeek 只在你主动启用并请求摘要时接收当前文章内容；
- DeepSeek 只在你主动使用摘要或语音搜索时接收相应的文章或音频内容；
- 不上传库内笔记、搜索词、已读状态或收藏；
- 订阅、文章缓存和状态保存在库的插件数据目录中；
- 图片和原文链接仍受对应网站的隐私政策和使用条款约束。
