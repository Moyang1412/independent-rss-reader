# Independent rewrite provenance

This project is an independent implementation of a local/personal RSS reader. It uses public RSS, Atom, OPML, Obsidian, DOM and Web APIs. It does not import source files, UI assets, fonts, brand names, or server code from Qiaomu AI RSS.

The reference project was used only to identify a possible product scope and to audit security and compatibility concerns. The current implementation has its own name, state model, module boundaries, UI text, CSS, and parser implementation. The project code is licensed under MIT; see `LICENSE`.

External dependencies are tracked in `package.json` and retain their own licenses. Feed articles, images, and other remote content remain subject to their own terms.
