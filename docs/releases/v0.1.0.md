# 本地 RSS 阅读器 v0.1.0

首个 MIT 版本。

## 这个版本包含

- RSS 2.x、RSS 1/RDF 和 Atom 解析；
- OPML 粘贴导入和库内导出；
- 个人订阅、分组、刷新、搜索、已读、收藏和稍后读；
- 安全的文章 HTML 渲染、URL 校验、XML 大小限制和 DTD/ENTITY 拒绝；
- 本地状态保存；
- 按 Obsidian 核心 Daily Notes 设置写入今日日记；
- 可直接安装的 Obsidian zip 包。

## 安装和使用

从本页下载 zip，解压到 `<你的库>/.obsidian/plugins/independent-rss-reader/`，然后在 Obsidian 的“设置 → 第三方插件”中启用“本地 RSS 阅读器”。

启用后，点击左侧 RSS 图标：

1. 点击“+”添加 RSS 或 Atom 地址；
2. 点击刷新按钮更新订阅；
3. 选择文章阅读、搜索、收藏或加入稍后读；
4. 点击“记到今日日记”，按 Obsidian 核心 Daily Notes 的目录、日期格式和模板设置追加文章链接。

## 当前边界

- 不接入乔木后端；
- 不包含播客、语音、实验室和 Agent 功能；
- 尚未完成实体 iOS/Android 和 Windows 宿主验收；
- 项目代码使用 MIT，依赖和远程 RSS 内容保留各自许可证与使用条款。
