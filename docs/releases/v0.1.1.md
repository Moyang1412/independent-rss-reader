# 本地 RSS 阅读器 v0.1.1

本次版本在首个 MIT 版本的基础上加入可选 DeepSeek 摘要适配器。

## 新增功能

- 在插件设置中配置 DeepSeek API Key、接口地址、模型和请求超时；
- 打开文章后点击“生成摘要”；
- 摘要使用 DeepSeek Chat Completions API 生成；
- 生成结果保存在当前 Obsidian 库的插件数据中，重复打开文章时可直接查看；
- 未配置 DeepSeek 时，RSS 添加、刷新、搜索、阅读、收藏和今日日记功能继续可用。

默认配置：

- 接口地址：`https://api.deepseek.com`；
- 模型：`deepseek-flash`；
- 摘要请求只发送当前文章的标题、摘要和正文。

## 安装和使用

从本页下载 `independent-rss-reader-0.1.1.zip`，解压到：

```text
<你的库>/.obsidian/plugins/independent-rss-reader/
```

在 Obsidian 的“设置 → 第三方插件”中启用“本地 RSS 阅读器”。然后打开插件设置，启用 DeepSeek 并填写 API Key。打开任意文章后，点击“生成摘要”。

## 当前边界

- 语音识别暂未加入，后续将单独接入 DeepSeek ASR；
- 不接入乔木后端；
- 不包含播客、实验室和 Agent 功能；
- API Key 只保存在本地插件数据中；
- 项目代码使用 MIT，依赖和远程 RSS 内容保留各自许可证与使用条款。
