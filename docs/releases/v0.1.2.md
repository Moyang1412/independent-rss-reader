# 本地 RSS 阅读器 v0.1.2

本次版本加入可选的 DeepSeek 语音识别，用于文章搜索。

## 新增功能

- 阅读器搜索框旁新增“语音搜索”；
- 支持选择 16-bit PCM WAV 或 Ogg Opus 音频；
- 识别结果自动填入本地文章搜索框；
- 本地校验文件大小不超过 8 MiB；
- DeepSeek 服务端限制音频时长不超过 120 秒；
- 请求只上传一个 `file` 字段，不发送 `model` 或 `language` 参数；
- 未配置 DeepSeek 时，原有 RSS 阅读功能继续可用。

## 使用

1. 在“设置 → 第三方插件 → 本地 RSS 阅读器”中启用 DeepSeek 并填写 API Key；
2. 打开本地 RSS 阅读器；
3. 点击搜索框旁的“语音搜索”；
4. 选择 WAV 或 Ogg Opus 音频；
5. 等待识别结果填入搜索框。

音频只会在你主动选择并开始识别时发送到 DeepSeek。语音识别不会自动写入日记或文章内容。

## 当前边界

- 暂不支持实时流式识别；
- 不支持 WebM、MP3 等未被 DeepSeek ASR 接受的格式；
- 不接入乔木后端；
- 项目代码使用 MIT，依赖和远程 RSS 内容保留各自许可证与使用条款。
