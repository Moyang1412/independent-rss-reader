# 本地 RSS 阅读器 v0.1.3

本次版本加入直接麦克风录音，用于 DeepSeek 语音搜索。

## 新增功能

- 搜索框旁新增“开始录音”和“停止录音”；
- 录音在本地编码为 16-bit PCM WAV；
- 录音结束后自动调用 DeepSeek ASR；
- 仍可选择已有 WAV 或 Ogg Opus 文件；
- 录音最长 120 秒；
- 关闭阅读器、取消或发生错误时释放麦克风和音频上下文；
- 只有点击“开始录音”后才会请求麦克风权限。

## 使用

1. 在“设置 → 第三方插件 → 本地 RSS 阅读器”中启用 DeepSeek 并填写 API Key；
2. 打开本地 RSS 阅读器；
3. 点击“开始录音”并说话；
4. 点击“停止录音”；
5. 等待识别结果填入搜索框。

如果不想使用麦克风，也可以点击“选择音频”上传 WAV 或 Ogg Opus 文件。

## 当前边界

- 不支持实时流式识别；
- 录音需要 Obsidian 的麦克风权限；
- 不支持 WebM、MP3 等未被 DeepSeek ASR 接受的文件；
- 不接入乔木后端；
- 项目代码使用 MIT，依赖和远程 RSS 内容保留各自许可证与使用条款。
