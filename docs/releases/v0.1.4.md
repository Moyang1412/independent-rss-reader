# 本地 RSS 阅读器 v0.1.4

本次版本完成阶段 0 基础整理，并加入订阅管理功能。

## 新增功能

- 状态版本从 v1 迁移到 v2；
- 自动清理旧的插件专属 Daily Note 目录字段；
- 订阅和文章状态增加结构校验；
- 右键编辑订阅地址、名称和分组；
- 暂停和恢复订阅；
- 单独刷新某个订阅；
- 全部刷新时跳过已暂停订阅；
- 显示未读数量、最近更新时间、暂停状态和刷新错误；
- 订阅右键管理菜单。

## 使用

在左侧订阅上点击右键，可以选择：

- 编辑订阅；
- 暂停或恢复订阅；
- 刷新此订阅；
- 删除订阅。

左侧订阅列表会显示未读数量和最近更新时间。网络刷新失败时，错误状态会保留在对应订阅上。

## 当前边界

- 删除时保留文章、拖动排序和 OPML 文件选择导入尚未加入；
- 不接入乔木后端；
- 项目代码使用 MIT，依赖和远程 RSS 内容保留各自许可证与使用条款。
