# 本地 RSS 阅读器 v0.1.5

本次版本完成阶段 1 剩余的订阅管理功能。

## 新增功能

- 删除订阅时可选择保留文章或同时删除文章；
- 保留的文章会进入“已保存文章”集合；
- 支持拖动左侧订阅调整顺序，并在本地保存；
- OPML 导入窗口支持选择 `.opml` 或 `.xml` 文件；
- 状态迁移版本升级到 v3，兼容已有 v1/v2 数据。

## 使用

右键订阅后选择“删除订阅”，再选择保留文章或删除文章。保留的文章可以从“已保存文章”中继续阅读。

拖动左侧订阅行即可调整顺序。运行“导入 OPML”命令后，可以粘贴内容或点击“选择文件”。
