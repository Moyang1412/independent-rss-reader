# 本地 RSS 阅读器 v0.10.0

本版本加入可选的文章翻译功能，同时保留原文和本地阅读能力。

## 新增功能

- 在设置中启用文章翻译并填写目标语言；
- 复用 DeepSeek 兼容 Chat Completions 配置，不新增远程服务类型；
- 只发送当前打开文章的标题、摘要和正文；
- 译文按文章 ID 保存在本地，显示在原文下方；
- 翻译失败、未配置 API 或关闭翻译时，本地 RSS 阅读、刷新、搜索和离线阅读继续可用；
- 状态迁移版本提升到 v10。

## 验证

- `npm run check`：通过，71 项测试通过，0 errors、52 条 lint 规则提示；
- 翻译适配器测试覆盖主动请求、输入截断、禁用状态、HTTP 错误和空文章；
- TypeScript 编译和 Obsidian 插件打包通过。

## 边界

- 翻译是显式点击触发的可选功能，不会自动翻译整库；
- 原文不会被替换，译文不会写回远程服务；
- 翻译服务、API Key 和目标语言由用户在本地设置中控制。
