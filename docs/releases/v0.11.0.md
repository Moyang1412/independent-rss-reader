# v0.11.0

本版本加入可选的 AI 辅助整理功能，保留本地 RSS 阅读和手工知识整理能力。

## 新功能

- 在设置中启用 AI 辅助整理并选择输出语言；
- 在当前文章页面按需生成标签、建议备注和一句话整理摘要；
- 建议按文章、模型、语言和提示版本缓存到本地；
- 只有点击“确认写入标签/备注”后，建议才会合并到文章知识数据；
- 手工标签会去重保留，手工备注不会被覆盖；
- 重复确认不会重复追加同一条 AI 建议；
- 翻译、摘要、语音和 AI 整理共用 DeepSeek 配置，但各自独立开关。

## 验证

- TypeScript 类型检查通过；
- 77 项测试通过；
- ESLint 无错误；
- 构建产物包含 `main.js`、`manifest.json`、`styles.css` 和 `LICENSE`。

## 边界

- 默认关闭；
- 只处理当前打开的文章，不自动处理整个订阅或整个库；
- 需要用户主动请求，并在确认后才修改标签和备注；
- 未配置 DeepSeek、请求失败或关闭功能时，本地阅读继续可用。
