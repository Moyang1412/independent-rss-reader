# 本地 RSS 阅读器 v0.12.0

本版本加入可选的 Dataview 集成，同时保留普通 Markdown 文章文件和本地 RSS 阅读能力。

## 新增功能

- 在“Obsidian 插件集成”设置中启用或关闭 Dataview 集成；默认关闭；
- 配置库内索引文件路径，默认是 `RSS Articles/RSS Articles Index.md`；
- 增加命令面板命令“生成 RSS Dataview 索引”和设置页“生成索引”按钮；
- 生成或更新一个普通 Markdown 索引文件，内含 `dataview` 查询；
- 默认显示文章链接、来源、发布时间和标签，并按发布时间倒序排列；
- 复用文章保存模板已有的 `source`、`published` 和 `tags` 字段，不调用 Dataview 的内部写入接口；
- 重复生成时幂等更新同一路径，不创建重复索引；
- 如果索引路径已有不是本插件生成的 Markdown 文件，会报错并保留原文件；
- 校验索引目录，阻止绝对路径、库外路径和 URL 被写入查询；
- 状态迁移版本提升到 v12。

## 使用方式

1. 先启用 Obsidian 的 Dataview 社区插件（可选）；
2. 打开“设置 → 第三方插件 → 本地 RSS 阅读器 → Obsidian 插件集成”；
3. 打开“启用 Dataview 集成”，并按需修改索引文件路径；
4. 通过命令面板运行“生成 RSS Dataview 索引”，或在设置页点击“生成索引”；
5. 打开索引文件查看 Dataview 表格。没有安装或没有启用 Dataview 时，文件仍是可读的普通 Markdown 代码块。

## 验证

- Dataview 索引渲染、默认字段、字段去重、标题换行清理和路径校验测试通过；
- 状态从 v11 迁移到 v12 后，旧订阅、文章、阅读状态和知识整理数据继续保留；
- 索引生成只写普通 Markdown，不依赖 Dataview 写入 API；
- 文章文件、RSS 刷新、阅读、离线缓存、Markdown 保存和 Daily Note 写入保持本地实现。

## 边界

- Dataview 集成是可选的，不改变 RSS 订阅、文章缓存或阅读状态的存储方式；
- 插件只写自己生成的普通 Markdown 索引，不向 Dataview 写入数据；
- 关闭 Dataview、卸载 Dataview 或索引生成失败时，本地 RSS 阅读器仍可继续使用；
- Templater 和 Calendar Plus 尚未作为强依赖接入，Daily Note 仍读取 Obsidian 核心日记设置。
