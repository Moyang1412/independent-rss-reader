# 本地 RSS 阅读器 v0.2.0

本次版本完成阶段 2 的第一批阅读效率功能。

## 新增功能

- 在阅读器工具栏将当前订阅全部标记为已读；
- 在文章页面使用“上一篇”和“下一篇”导航；
- 使用 `j`/`k` 或方向键切换可见文章；
- 使用 `r` 刷新当前订阅；
- 在文章列表和正文中显示文章来源；
- 增加“最近 7 天”文章筛选。

快捷键只在阅读器内容区域生效。搜索框、输入框和可编辑区域获得焦点时不会拦截键盘输入。

## 验证

- `npm run check`：32 项测试通过，0 个错误；
- 插件安装包包含 `main.js`、`manifest.json`、`styles.css` 和 `LICENSE`。
