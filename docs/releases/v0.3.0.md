# 本地 RSS 阅读器 v0.3.0

本次版本完成阶段 2 剩余的阅读效率功能。

## 新增功能

- 进入“选择文章”模式后批量收藏；
- 批量加入稍后读；
- 按发布时间在“最新在前”和“最早在前”之间切换；
- 按订阅记录最后打开的文章，重新打开阅读器时恢复；
- 状态迁移升级到 v4，旧状态会自动补充阅读位置字段。

## 使用

在文章列表上方点击“选择文章”，可以全选当前筛选结果，再执行批量收藏或批量加入稍后读。

点击“排序：最新在前”按钮可切换为最早在前。列表排序会影响上一篇/下一篇和键盘导航顺序。
