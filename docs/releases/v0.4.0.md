# 本地 RSS 阅读器 v0.4.0

本次版本完成阶段 3 的自动刷新基础能力。

## 新增功能

- 在插件设置中启用或关闭自动刷新；
- 设置刷新间隔，范围为 1 到 1440 分钟；
- 设置打开 Obsidian 并完成布局后自动刷新；
- 自动刷新跳过暂停订阅；
- 成功刷新后提醒新增文章数量；
- 失败订阅记录失败次数，并按 5、10、20 分钟递增退避，最长 6 小时；
- 手动刷新、打开时刷新和定时刷新共用同一套请求状态；
- 状态迁移升级到 v5，保存刷新设置和最近一次刷新汇总。

## 验证

- `npm run check`：41 项测试通过，0 个错误；
- 在临时 QA 库中检查自动刷新设置、打开时刷新失败记录、暂停订阅跳过刷新和失败退避逻辑。
