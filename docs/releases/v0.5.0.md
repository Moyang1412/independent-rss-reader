# 本地 RSS 阅读器 v0.5.0

本次版本完成阶段 4 的离线缓存基础能力。

## 新增功能

- 保存完整正文，刷新失败或断网时继续阅读已有文章；
- 将正文图片下载到插件缓存目录，并在阅读时优先使用本地图片；
- 右键编辑订阅时设置该订阅的缓存上限；
- 自动合并新旧文章并清理超出上限的旧文章；
- 清理不再使用的图片文件；
- 清理时保护未读、收藏和正文仍在使用的缓存；
- 状态迁移升级到 v6，保存缓存设置和图片缓存元数据。

## 验证

- `npm run check`：43 项测试通过，0 个错误；
- 在 QA 库中保留断网刷新后的文章内容，并验证缓存设置入口；
- 纯逻辑测试覆盖缓存上限、保护未读/收藏文章和图片 URL 去重。
