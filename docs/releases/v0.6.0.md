# 本地 RSS 阅读器 v0.6.0

本次版本完成阶段 5 的知识整理能力。

## 新增功能

- 为文章添加标签和备注，并在阅读视图中显示；
- 将文章按模板保存到指定的 Markdown 文件夹；
- 支持自定义文章保存模板和 Daily Note 插入格式；
- 提供标题、来源、作者、发布时间、原文链接、摘要、Markdown 正文、标签和备注变量；
- 记录每篇文章的保存路径，重复保存同一文章时跳过；
- 清理本地条目 ID 中的路径不安全字符，保证 `local:...` 条目可以保存；
- 状态迁移升级到 v7。
