# 本地 RSS 阅读器 v0.7.0

本次版本完成阶段 6 的订阅兼容性和健康检查能力。

## 新增功能

- 从站点首页自动发现 RSS、Atom 或 RDF 订阅地址；
- 跟随 `rel="next"` 分页，最多抓取 5 页并合并文章；
- 跨分页按源条目 ID 去重；
- 解析分类、评论地址、媒体地址和媒体类型等扩展字段；
- 解析相对链接、站点名称、站点地址、描述、语言、生成器、图标和封面；
- 右键订阅或命令面板运行健康检查；
- 对超时、网络、证书、重定向、HTTP 状态和 malformed XML 显示可读错误；
- 状态迁移升级到 v8。

## 验证

- `npm run typecheck`：通过；
- `npm test`：58 项测试通过；
- `npm run lint`：0 errors，42 条规则提示；
- 固定 RSS/Atom fixture 覆盖扩展字段、分页链接、自动发现、相对链接和 malformed XML；
- 请求测试覆盖自动发现、分页合并、重复条目去重、重定向、HTTP、网络和证书错误分类。

## 当前边界

- 不接入乔木后端；
- 分页抓取最多 5 页，每次最终保留最多 50 篇文章；
- 项目代码使用 MIT，依赖和远程 RSS 内容保留各自许可证与使用条款。
