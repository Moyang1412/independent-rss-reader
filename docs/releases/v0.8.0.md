# 本地 RSS 阅读器 v0.8.0

本次版本完成阶段 7 的窄屏、移动端和无障碍基础能力。

## 新增功能

- 使用容器查询适配窄面板和 320px 宽度；
- 移动触摸设备上的按钮、输入框和链接使用至少 44px 的触摸目标；
- 增加跳到文章列表的 skip link、`main` landmark、控件 accessible name 和焦点环；
- 支持 `j`/`k`、方向键、`Home`、`End` 和 `r` 键盘操作；
- 文章数量较多时只渲染当前可见窗口，并保留滚动占位高度；
- 虚拟列表保留文章选择、筛选、批量操作、未读状态和键盘导航；
- 适配 Obsidian 深色/浅色主题和原生表单控件颜色。

## 验证

- `npm run typecheck`：通过；
- `npm test`：60 项测试通过；
- `npm run lint`：0 errors，43 条规则提示；
- Obsidian QA 库验证桌面布局、无障碍文章名称、站点名称、筛选和现有阅读操作；
- 通过固定窗口范围测试验证虚拟列表的可见区、overscan、边界和选中项保留。

## 当前边界

- 移动端真实设备触摸行为仍需在 Android/iOS Obsidian 上继续验收；
- 项目代码使用 MIT，依赖和远程 RSS 内容保留各自许可证与使用条款。
