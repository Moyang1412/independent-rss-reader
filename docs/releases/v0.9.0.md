# 本地 RSS 阅读器 v0.9.0

本版本加入可插拔的远程只读服务适配器，同时保留本地 RSS 作为主要阅读路径。

## 新增功能

- 增加远程只读适配器注册表，后续可以增加其他服务提供商；
- 内置 `json` 适配器，通过 GET 读取 `/subscriptions`；
- 支持订阅返回 `entries`、`articles` 或 `items` 文章数组；
- 校验远程地址、HTTP 状态、JSON 格式、文章字段和请求超时；
- 可选发送 Bearer API Key，但不会执行远程写入；
- 远程订阅保存为本地快照，并绑定适配器 ID、远程订阅 ID 和只读标记；
- 本地已读、收藏、稍后读、缓存、标签、备注、Markdown 保存和 Daily Note 写入继续由本地插件管理；
- 远程适配器默认关闭，未配置远程服务时本地 RSS 功能不受影响；
- 状态迁移版本提升到 v9。

## 验证

- `npm run check`：通过，66 项测试通过，0 errors、47 条 lint 规则提示；
- 单元测试覆盖适配器注册、URL 校验、Bearer 认证、GET 请求、JSON 解析、错误和快照合并；
- Obsidian QA 库验证本地订阅继续可添加、刷新和阅读，远程能力保持可选。

## 边界

- 本版本只提供只读快照读取，不向远程服务写入订阅、阅读状态或文章操作；
- 远程服务的具体部署、认证策略和返回数据格式由服务提供方负责；
- 移动端真实设备触摸验收仍沿用 v0.8.0 的边界。
